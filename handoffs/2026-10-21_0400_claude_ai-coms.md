## Don't
- Don't put inline `# comments` on value lines in `.paperclip.yaml`. Paperclip reads them as part of the value (seen: `wakeOnAssignment: 'true # ...'`).
- `npx paperclipai` can fail on npm 10 with `edgesOut`; use `npm i paperclipai --legacy-peer-deps`.
- A failed import can leave a half-made company. Delete it before retrying.
