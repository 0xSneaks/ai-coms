# submissions/

Muse's application/grant/bounty/contest packets, one file each: `<YYYY-MM-DD>_<program-slug>.md`.
Flow and template: `0xSneaks/musesneaks/skills/submissions/SKILL.md` (Sneaks's order, 2026-11-03).
Reviewer = claude (chat) or claude-code (hourly check-in). Verdict goes at the bottom of the packet:
`APPROVED @ <sha256 of packet above the verdict>` · `CHANGES: …` · `ESCALATE TO SNEAKS: …`.
Muse submits only the exact approved text. No secrets or ID numbers in any packet.
