## Notes

- **kimi-k3.1-pro privacy (UNKNOWN):** the model is not in the OpenCode Go catalog, so no Go-route data terms exist. Moonshot's maker-side position could not be settled from an official page in this pass: third-party readings of Moonshot's own documents conflict (the consumer privacy policy reportedly allows training use of user content with an email opt-out, while an API security FAQ is reported to say API inputs/outputs are not used for training, and the Open Platform terms reportedly permit training use unless restricted in writing). Recorded UNKNOWN rather than guessing; a direct read of Moonshot's platform terms/ZDR page is the follow-up.
- **minimax-m3.1-flash weights timing:** MiniMax's official release notes describe M3.1 Flash as an "open-weight model," but the launch blog (minimax.io, published 2026-10-19) says "Model weights will be released later." Open-weight status is the maker's stated intent/status; the exact release timing of the weights is ambiguous between the two official pages.
- **minimax-m2.7 context source:** the live MiniMax API docs have dropped M2.7 from the Supported Models table (M2.5/M2.7 hosted families retire 2026-11-18 and plan traffic is rerouted to M3.1 Flash). The 204,800 figure comes from an archived snapshot of MiniMax's official API Overview docs page, which lists "MiniMax-M2.7 — 204,800" (max token count = input + output combined).
- **qwen3.8-flash / qwen3.7-plus weights (UNKNOWN, not "closed"):** no open-weights announcement was found on the official Qwen blog, Alibaba Cloud Model Studio docs, or Qwen's HF presence checked in this pass; both models are documented there as hosted API models. Absence of a release announcement is not an official closed-weights statement, so the cells say UNKNOWN. (Caution: "Qwen3.8-Flash-Next" appears in third-party coverage as a separate open checkpoint — do not conflate it with qwen3.8-flash.)
- **MiMo license basis:** "MIT" is the license tag in the Hugging Face repo metadata of Xiaomi's official XiaomiMiMo repos. The card bodies themselves carry a "Use Restrictions" notice that references "the applicable model licence" without naming it, and Xiaomi's mimo.mi.com model pages do not state a license — so the open-weights fact is first-hand (weights downloadable from the maker's repos), while the MIT name rests on the HF metadata tag.
- **MiMo on Go:** OpenCode Go's catalog lists MiMo-V2.5 / MiMo-V2.5-Pro, which Xiaomi retired on 2026-10-21 in favor of the V2.6 series; the V2.6 models themselves are not in the Go docs fetched for this rundown, hence "see platform facts."
- **Kimi context figures:** Moonshot's pricing page gives exact powers of two (K3 series 1,048,576; K2 series 262,144); the HF cards round these to "1M" / "256K". Table uses the exact pricing-page numbers.
- **Alibaba maker-route privacy (applies to all three Qwen rows off-Go):** Model Studio FAQ — "Alibaba Cloud strictly protects data privacy and never uses your data for model training"; Data Retention Policy — prompts/responses retained "no longer than 30 days" by default, with a Zero Data Retention option (enterprise, workspace-level) under which data is not written to durable storage; ZDR-supported series explicitly include qwen3.8-max, qwen3.7-plus, and qwen3.8-flash.
