## Notes

- **Platform facts (OpenCode, official):** Go plans are Go $10/mo, Go Plus $40/mo, Go Teams $20/member/mo. Per-model monthly dollar limits above are the base (Go) plan limits; each model's 5-hour limit is 20% of monthly and weekly is 50% (Go docs). The Go privacy table (training/retention per model) is the source for all seven Go models in this lane — all seven are "Not used" / "0 days". Source: https://opencode.ai/v2/docs/console/go
- **The `:free` Nemotron ids are aggregator-style labels.** OpenCode's own ids are `nemotron-3-ultra-free`, `nemotron-3.5-lightning-free`, `nemotron-3.5-super-vl-free` on OpenCode Console (pay-as-you-go catalog, priced Free). None of the three is a Go subscription model. `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free` does not appear in either OpenCode catalog (Go list and Console list both checked in full on 2026-11-03).
- **mistral-large-3:675b** is likewise not an OpenCode Go/Console id — Console carries Mistral Large 4 only. Mistral's own docs mark Large 3 (v25.12) **deprecated**, deprecation date 10/31/2026, replacement Mistral Large 4.
- **GLM license names:** Z.ai's docs and HF cards confirm open weights for glm-5.2 / glm-5.3 / glm-5.3-flash, but the fetched official pages did not render a license name (HF page metadata is stripped in text fetch). Secondary coverage reports MIT for GLM-5.2 and GLM-5.3-Flash and a custom "glm-5.3" license for GLM-5.3 — **not verified on an official page, so not recorded as fact above.**
- **step-5-preview max output discrepancy:** StepFun's platform docs state max output 64k (context 1M, max input 1M), while the HF card's spec table states "Maximum Output: Up to 1M tokens". Context is 1M on both.
- **longcat-2.0 context:** Meituan's card does not print a separate max-context spec line; it states the model was trained on "hundreds of billions of tokens of 1M-context data" with LongCat Sparse Attention for long-horizon tasks. Recorded as 1M on that basis.
- **NVIDIA free-endpoint privacy applies to the hosted trial route** (build.nvidia.com / OpenCode Console free endpoints), not to self-hosted open weights. NVIDIA's trial terms also say "Trial use only — do not submit personal or confidential data."
- **Maker-direct privacy** (Tencent, StepFun, Meituan, Z.ai, Mistral, NVIDIA API terms) was not pulled from separate maker policy pages for most rows; the privacy columns reflect the OpenCode route actually used by the bench. Where the OpenCode page itself defers (Mistral) or is silent (Nano Omni), the cell is UNKNOWN rather than filled.
