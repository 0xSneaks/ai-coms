## Notes

- **ID mapping (DeepSeek):** `deepseek-flash` and `deepseek-v4.1-flash` are the same underlying model (DeepSeek-V4.1-Flash-1017) under two ids — DeepSeek's own API uses `deepseek-flash`; OpenCode Go uses `deepseek-v4.1-flash`. Legacy `deepseek-v4-flash` ids route to V4.1 Flash. Source: DeepSeek's official pricing page.
- **Go allowance figures** are the monthly dollar-equivalent usage limits on the $10/month OpenCode Go plan; OpenCode splits each model's limit 20% per 5 hours / 50% per week / 100% per month. Go Plus and Go Teams plans differ. OpenCode also states it blocks paid endpoints that train on request data by default (workspace privacy settings). Source: https://opencode.ai/docs/go/
- **DeepSeek direct-API privacy is UNKNOWN, deliberately.** No official DeepSeek privacy/data-policy page could be retrieved this run — searches surfaced only third-party analyses of DeepSeek's policy (which describe training-by-default with an opt-out, no fixed retention window, and storage in the PRC). Those are NOT recorded as facts above. The verified privacy facts for the two DeepSeek rows are for the OpenCode Go route only.
- **Anthropic cross-check:** Anthropic's own data-usage docs independently match the Go-route row — no training on prompts/code under commercial terms (API included) unless the customer opts into a partner program; standard commercial retention 30 days; zero-data-retention available to qualified accounts.
- **xAI branding:** xAI's current official developer docs (page updated Oct 10, 2026) brand the maker "SpaceXSI" ("SpaceXSI's frontier model", "SpaceXSI never trains on your API inputs or outputs…"). The model id and API host (api.x.ai) are unchanged.
- **Gemini API terms detail:** under the official Gemini API Additional Terms (effective March 23, 2026), users in the EEA, Switzerland, or the UK get the Paid-Services data terms even on unpaid quota. Paid-service prompt/response logging is described only as "for a limited period of time" — no day count — so retention is UNKNOWN rather than guessed.
- **Gemma privacy:** the official Gemma 4 model card covers weights, license, and specs only; it does not state prompt-training or retention terms. Self-hosting the open weights means no data leaves your infrastructure; consuming Gemma through Google's Gemini API would fall under the Gemini API terms above.
- **gpt-oss:120b id form:** the colon-style id is the Ollama tag form of OpenAI's `gpt-oss-120b`. OpenAI's launch materials list a 128K context length; many third parties list 131,072 — OpenAI's own figure is used above. OpenAI's help center confirms gpt-oss is not served through the OpenAI API.
- **gemini-3-flash-preview context:** third-party sources consistently report 1,048,576 input / 65,536 output tokens, and Google's models index confirms the id exists as a Preview model, but the per-model numbers were not read from an official Google page this run, so the cell stays UNKNOWN per the official-sources-only rule.
