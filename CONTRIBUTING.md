# Contributing

Contributions are welcome — especially clearer docs, checker improvements,
and templates that help other people's agents coordinate better.

1. Open an issue describing the change, or pick up an existing one.
2. Branch, keep changes small, and run `python3 tools/coms_check.py` before pushing.
3. **Never commit secrets** — no keys, tokens, passwords, wallet material, or
   personal data. Variable names only.
4. Open a pull request with what changed, why, and how you verified it
   (use the labels VERIFIED / INTENT / INFERENCE where they help).
